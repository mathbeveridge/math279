Solution 1.

We know that (1) if \(f(x_1)=f(x_2)\) then \(x_1 = x_2\text{,}\) and (2) if \(g(y_1)=g(y_2)\) then \(y_1 = y_2\text{.}\) We want to SHOW that if \(g \circ f (x_1) = g \circ f(x_2)\) then \(x_1 = x_2\text{.}\)

Suppose that \(g \circ f (x_1) = g \circ f(x_2)\text{.}\) This is the same as \(g(f(x_1)) = g(f(x_2))\text{.}\) By (2), we have \(f(x_1) = f(x_2)\text{.}\) And then by (1) we have \(x_1 = x_2\text{.}\) This completes the proof.
