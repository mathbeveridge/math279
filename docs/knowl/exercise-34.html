Exercise 2. Is the mapping a function?

Consider the following mappings from domain \(X= \{ x \in \mathbb{R} : 0 \leq x \leq 5 \}\) to codomain \(Y= \{ x \in \mathbb{R} : -10 \leq x \leq 10 \}\text{.}\) Decide whether each of the following mappings is a function. Justify your answers.

  1. \(\displaystyle f(x) = 2x\)

  2. \(\displaystyle f(x) = x^2\)

  3. \(\displaystyle f(x) = \pm \sqrt{x}\)
